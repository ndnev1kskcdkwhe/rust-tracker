# CLAUDE.md — контекст проєкту

## Що будуємо

Сайт для гравців Rust: пошук інформації про гравців і сервери (у стилі rustwho.com) + власні ігрові калькулятори. Монетизація — підписка: free-рівень з лімітами, платні рівні без обмежень.

## Стек

- Фронтенд: Next.js (App Router), TypeScript, Tailwind
- Бекенд: Next.js API routes
- БД: PostgreSQL + Prisma (заміни на Drizzle, якщо тобі так зручніше)
- Оплата: Stripe — підключається з фази 5, не раніше
- Хостинг: Vercel + керований Postgres (Supabase / Neon / Railway)

## Зовнішні API

| Джерело | Навіщо | Де взяти ключ |
|---|---|---|
| Steam Web API | профіль, VAC/game-бани | steamcommunity.com/dev/apikey |
| BattleMetrics API | сесії, історія імен, бани, сервери | battlemetrics.com → Developers |
| RustMaps API | прев'ю мапи за seed+size, монументи | rustmaps.com/dashboard |
| Rust+ Companion API | алерти (фаза 6, не зараз) | офіційний, через Facepunch акаунт |

Усі ключі — у `.env.local`. Ніколи в коді, ніколи в git.

## Правила роботи

- Рухайся фазами нижче, по порядку. Не починай наступну, поки попередня реально не працює.
- Перед нетривіальною фічею — спочатку опиши план (які файли, яка структура даних), почекай на підтвердження.
- Усе, що береш із зовнішніх API, — кешуй у своїй БД. Живий запит до Steam/BattleMetrics на кожен пошук користувача неприпустимий.
- Пиши код так, щоб легко додавати нові фічі — ідеї будуть докидатись по ходу розробки.
- Якщо чогось бракує (ключа API, рішення) — скажи прямо і зупинись. Не імітуй робочу логіку заглушками, які виглядають як готовий код.

## Фаза 1 — каркас

- `npx create-next-app@latest` (TypeScript, App Router, Tailwind, ESLint)
- Postgres + Prisma, базові моделі User і Subscription
- Проста авторизація (NextAuth або email+пароль)
- Git-репозиторій, README із кроками запуску

Готово, коли: `npm run dev` піднімає порожній сайт із логіном

## Фаза 2 — калькулятори (без зовнішніх API)

- Рейд. Вхід: тип конструкції, сторона (м'яка/тверда), доступна вибухівка.
  - влучень = ceil(HP / (шкода_за_удар × (1 − resistance)))
  - Знайди найдешевшу комбінацію за вартістю сірки/ресурсів. Значення HP/resistance/шкоди актуальні на rustlabs.com і wiki.rustclash.com — сходи туди й візьми реальні цифри, не покладайся на власну пам'ять про баланс гри (він міняється патчами).
- Фермерство. Вхід: ресурс, інструмент, множник збору сервера (типово 1x). Вихід: скільки ударів/часу треба на задану кількість ресурсу.
- Обидва — чисті функції, без БД і без зовнішніх викликів. Покрий юніт-тестами.

## Фаза 3 — пошук гравців

- Форма пошуку за SteamID або посиланням на профіль
- Об'єднай Steam (профіль, бани) + BattleMetrics (сесії, історія імен, сервери) в один DTO
- Кешуй у БД на 15–60 хв — повторний пошук того самого гравця не має щоразу бити по зовнішніх API
- Сторінка профілю: аватар, ім'я, години, історія імен, бан-статус, останні сервери

## Фаза 4 — сервери і мапи

- Пошук сервера через BattleMetrics: населеність, ранг, адреса
- RustMaps: прев'ю мапи за seed+size + список монументів
